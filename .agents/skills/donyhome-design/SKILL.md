# 도니홈 디자인

도니홈의 UI 작업에는 [디자인 규칙](../../../docs/design-system.md)을 적용한다. 규격의 구현 원본은 `Sources/DonyClean/Theme.swift`와 `DonyControls.swift`다. SwiftUI 네이티브 메뉴의 기본 모양이 공통 규격과 같다고 가정하지 않는다.

- 화면 행동은 오른쪽, 이름·상태는 왼쪽에 둔다. 카드마다 주요 행동은 한 개로 정하고 나머지는 공통 메뉴에 넣는다.
- 설정 행동은 `SettingsActionRow`, 글자 메뉴는 `DonyMenuButton`, 더보기는 `DonyIconMenu`를 사용한다. 화면 파일에 메뉴의 화살표·배경·프레임을 다시 만들지 않는다.
- 규격 변경은 공통 컴포넌트에서 하고 모든 사용처를 확인한다. 문서만 고치거나 한 화면에만 예외 스타일을 덧붙이지 않는다.
- 설명은 결정을 돕는 경우에만 표시한다. 경고, 권한 부족, 영구 삭제, 작업 중 상태는 생략하지 않는다. 내부 용어와 중복 버튼은 노출하지 않는다.
- 요청된 UI 상태를 실제 화면에서 검증한다. 메뉴는 닫힘/열림/키보드 Escape, 버튼은 활성/비활성, 목록은 빈 결과/선택/긴 이름을 확인한다. 삭제·권한 허용은 외관 검증을 위해 실행하지 않는다.
- `python3 scripts/check-design-rules.py`와 릴리스 빌드를 실행한다. 스킬 구조는 skill-creator의 `quick_validate.py`로 확인한다. 검증한 화면과 남은 제한을 결과에 기록한다.

제품의 명시적인 새 요구사항은 이 규칙보다 우선한다. 필요한 예외는 공통 변형으로 구현하고 디자인 규칙에 이유와 적용 범위를 기록한다.
