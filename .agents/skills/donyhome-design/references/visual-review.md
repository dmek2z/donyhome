# 도니홈 실제 화면 비교 기준

`../assets/development-reference.png`는 2.2.1 앱의 960pt 폭에서 확인한 실제 개발 화면이다. 화면을 만들거나 고칠 때 이미지를 열어 공통 정렬과 정보 위계를 비교한다. 값·도구 수·버전은 예시이며 복사할 데이터가 아니다. 맨 위 보라색 공유 표시와 창 버튼은 OS 요소이며 제품 디자인에 추가하지 않는다. 이 이미지는 모든 화면이 검증됐다는 증거가 아니다.

## 비교할 항목

| 요소 | 공통 기준 |
|---|---|
| 사이드바 | 이름 왼쪽 정렬, 아이콘 열 동일, 선택 배경 전체 클릭 가능 |
| 제목·탭 | 제목 28pt, 탭 아래 가는 선, 같은 왼쪽 시작점 |
| 카드 | 같은 20pt 모서리, 24pt 안쪽 여백, 20pt 간격 |
| 실행 | 오른쪽 정렬, 42pt 높이, 주요 검사 한 개 |
| 요약 수치 | 같은 기준선, 같은 폰트·자릿수 처리, 측정 기준은 툴팁 |
| 목록 | 두 줄 행 64pt, 동일 구분선·열 정렬, 긴 이름 한 줄·전체 경로 툴팁 |
| 선택·설정 | 행·칩·분할 선택·직접 버튼, 글자 드롭다운 없음 |
| 문구 | 제목·값·실제 상태 중심, 기능 소개·중복 설명 없음 |

## 실제 화면 확인

- 기준 폭은 960pt와 1130pt다. 최소 높이에서 본문·사이드바 스크롤이 동작하고 수치·실행 버튼이 겹치지 않는지 확인한다. 다른 표시 배율에서는 사진의 물리 픽셀이 아니라 앱의 pt 규격을 기준으로 비교한다.
- 변경한 화면에서 빈 결과·긴 이름/목록·선택·비활성 상태를 확인한다. 설정창을 추가/변경하면 열기·닫기와 버튼 정렬도 확인한다.
- 공통 선택 컴포넌트를 바꾸면 개발 목록뿐 아니라 캐시/파일/CPU·메모리의 사용처를 확인한다. 파괴적 실행 대신 선택·해제까지만 검증한다.
- 앱에 포함된 Pretendard/Fredoka·아이콘이 로드되는지, 시스템 accent나 밝기 설정에 의해 버튼·텍스트 모양이 바뀌지 않는지 확인한다. 다른 물리 Mac을 확인하지 못했다면 그 범위를 명확히 적는다.
- 캡처할 때 빌드한 앱의 버전·실행 경로를 확인한다. 다른 체크아웃의 이전 앱을 실행한 캡처로 검증을 대신하지 않는다.

기준 화면과 다른 부분은 실제 오류/보호 상태 또는 사용자가 요구한 변화인지 먼저 판단한다. 필요한 변경은 공통 규격으로 반영하고 기준 자료를 갱신한다. 사용자가 화면 변경을 요청할 때마다 별도의 디자인 승인을 반복해서 요구하지 않는다.
