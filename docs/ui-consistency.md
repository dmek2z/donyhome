# UI 정리 기록 · 2026-10-13

공통 규칙: 화면 제목/수치는 왼쪽, 화면·카드 행동은 오른쪽. 기본 실행은 영역마다 한 개, 보조 행동은 회색 버튼 또는 메뉴. 버튼 높이42pt, 모서리10pt, 카드 여백24pt, 설정 행동 열128pt. 목록의 전체 선택/선택 해제는 공통 선택 메뉴. 파일 이동은 선택 후에만 표시. 취소/실행 확인창은 전체 경로를 유지하며 위험한 작업의 기본 키는 취소.

| 화면 | 수정 |
|---|---|
| 한눈에 보기 | 중복 자동 정리/바로가기 제거, 검사 결과 상세 접기, 남은 공간 막대 의미 수정 |
| 캐시·로그 | 임시 파일 검사로 역할 한정, 자동 정리 설정 이동, 개발 캐시 분리, 공통 선택 메뉴 |
| 파일 검사 | 모든 탭에서 공통 폴더/검사 행, 사진/중복 원본 보호 유지, 공통 선택 메뉴 |
| 폴더 용량 | 이름 명확화, 항목 hover/탐색과 정리 선택 분리 |
| CPU·메모리 | 두 개의 작은 요약, 메모리순 기본 목록, 검색/정렬/선택 한 행, 고급 정보 접기 |
| 개발 | 개발 캐시 이동, 프로젝트 도구 연결 접기, 도구 링크가 아닌 고유 폴더 수 표시 |
| 앱 관리 | 로그인 설정 중복 진입 제거, 남은 앱 파일 명칭과 위험 설명, 공통 선택 메뉴 |
| 유지보수 | 기능별 오른쪽 행동 열, 휴지통 메뉴 통합, 백업 명칭 자연스럽게 수정 |
| 정리 기록 | 경로/결과 상세 접기, 항목 보기 오른쪽 배치 |
| 설정/온보딩 | 행동 행 공통화, 컬러/흑백의 여유/과부하 애니메이션 미리보기 |
| 메뉴 팝업 | 기존 단일 앱 열기 유지, 같은 캐릭터 상태 적용 |
| 권한/확인창 | 실제 접근 거부 분류, 권한 안내, 앱 디자인 확인창, 모든 대상 경로 표시 |

권한은 사용자가 macOS에서 허용합니다. 파일 상태 변경/링크/실행 중인 앱은 권한 오류로 오인하지 않습니다. 테스트에서는 사용자 파일 삭제와 앱 종료를 실행하지 않습니다.

검증: 83개 테스트. Music 캐시의 시스템 폴더 읽기 응답 지연을 실측하여 해당 경로만 선제 제외합니다. 다른 임의 경로의 커널 I/O 응답 지연을 모두 시간 제한하는 구조는 아닙니다. 접근 거부와 응답 지연은 구분합니다.

실제 캐시 검사 완료: 26개 중 12개는 접근 거부, 14개는 기타 건너뛰기. 권한 안내창 표시와 Escape 취소를 확인했습니다. 주 화면 9개와 설정/사진 탭의 탐색·레이아웃을 확인했습니다. 파일 검사 전체 대용량 데이터와 모든 도구 설치 조합은 별도 검증 범위입니다.
