# 2.1.3 실제 화면 검증

2.1.2의 소스 리뷰는 macOS Menu 라벨 이미지의 네이티브 변환 문제를 발견하지 못했다. 잠금 해제 후 실제 클립보드 설정에서 화살표가 원본 PDF의 큰 크기로 표시되는 것을 재현했다.

수정: 네이티브 Menu 라벨에는 Text만 넣고 장식은 바깥 overlay에서 정해진 크기로 그린다. MenuHitAreaStyle로 컨트롤 전체 클릭 영역을 지정한다. 클릭 대상인 네이티브 메뉴의 opacity를 낮추지 않는다. 장식은 allowsHitTesting(false)로 클릭을 전달한다. 문자 메뉴와 더보기 메뉴에 같은 원칙을 적용한다. 규칙 검사에서 네이티브 라벨 안에 이미지를 다시 넣는 변경을 거부한다.

실제 앱 검증:
- 클립보드 설정의 검색 방식: 정상 화살표 크기, 가운데 글자, 왼쪽 빈 영역 클릭, 오른쪽 화살표 클릭, 메뉴 열기와 Escape 닫기 확인.
- 클립보드 기록: 공통 64pt 행과 더보기 메뉴의 정상 크기·열기 확인. 기록 변경·붙여넣기·삭제는 실행하지 않음.
- 유지보수: 공통 행동 버튼과 관리 메뉴의 동일한 오른쪽 끝과 크기 확인.
- 설정: 행동 버튼 오른쪽 정렬, 권한 상태 확인 중 → 접근 가능/권한 필요 전환 확인. 권한 허용은 실행하지 않음.
- 도니: 경력 목록을 제거하고 소개와 만든 이유만 표시되는 실제 화면 확인.

릴리스 빌드·서명·디자인 규칙·diff 구문 검사를 통과했다. 첫 설치의 OS 권한 팝업 전체 흐름은 실제 사용자 설정을 초기화하거나 변경하지 않기 위해 재현하지 않았다.
