# 2.1.2 디자인 리뷰

기준: docs/design-system.md와 도니홈 디자인 스킬. Sources/DonyClean 화면 소스 전체를 독립 리뷰하고 다음 사항을 수정했다.

- 도니 소개는 하단 고정 메뉴로 배치하고 다른 메뉴와 동일한 폭과 클릭 영역을 적용했다.
- 정리 기록은 64pt 요약 행과 별도 펼침 상세로 정리했다. 항목 보기 행동은 오른쪽에 배치했다.
- 폴더 용량 막대는 이름·용량을 접근성으로 제공하는 버튼으로 변경했다. 목록의 이름·용량·화살표 전체에서 탐색할 수 있다.
- 클립보드 단축키 버튼은 SettingsActionRow의 128pt 폭을 유지한다. 단축키 입력 안내는 별도 상태 글자로 표시한다.
- Time Machine 삭제 버튼의 폭을 통일하고 백업 시점 선택은 공통 문자 메뉴를 사용한다.
- LinkedIn은 Phosphor fill 아이콘을 사용한다. 원본 SVG와 PDF, 기존 MIT 라이선스가 포함된다. PDF를 이미지로 렌더링해 모양을 확인했다.
- Fredoka 글꼴의 라이선스를 앱 정보에서 확인할 수 있다.

소개 글과 경력은 사용자가 제공한 이미지와 현재 업무 설명을 기준으로 작성했다. Notion과 LinkedIn 본문은 외부 접근 제한으로 읽지 못했다.

검증: 디자인 규칙 검사, git diff --check, 전체 릴리스 빌드와 앱 서명 검증. Mac이 잠겨 있으므로 네이티브 화면 정렬·작은 창·키보드 탐색의 실제 확인은 남아 있다. 소스 리뷰 통과를 네이티브 시각 검증 완료로 간주하지 않는다. 사용자 파일 삭제나 권한 변경은 실행하지 않았다.
