# 도니클린 로컬 도구 확장

사용자가 CleanMyMac 비교에서 로컬로 구현 가능한 누락 기능의 개발을 승인했다. 기존 Foundation 후보·변경 재검증·휴지통 계약과 Dony/Phosphor UI를 유지한다.

범위: Vision 로컬 유사 사진 비교(수동 선택·보관 사진 교체·자동 추천 교차 보호, 최대 200장), 정확한 Xcode DerivedData 및 npm/pip/Homebrew 다운로드 캐시 후보; 설치/실행 앱 ID가 없는 Library 잔여물 후보(삭제 확정 아닌 검토 목록); 선택 폴더의 180일 이상 미변경 파일 및 dmg/pkg/iso 설치 파일; 하위 폴더별 용량 지도와 드릴다운; 실제 배터리와 물리 네트워크 전송률; 선택 실행하는 DNS 캐시 초기화, Spotlight 재색인, Time Machine 로컬 스냅샷 목록/선택 제거.

개발 캐시 자동 추천은 7일 이상 변하지 않고 관련 도구가 실행되지 않을 때만 한다. DerivedData 하위 프로젝트의 Build/Index/noindex 생성물과 재생성 가능한 다운로드 캐시만 포함하며 Xcode Archives·기기 지원·프로젝트 원본·패키지 저장소는 제외. 앱 잔여물은 정확한 ID 형식, 설치 목록 + LaunchServices + 실행 앱 확인으로 추리지만 자동 추천에 넣지 않는다. 실행 직전 설치 여부와 실행 여부 다시 확인한다.

오래된 파일·설치 파일·폴더 용량 항목은 직접 선택. 통합 검사에는 새 분류와 개발 캐시, 잔여물도 포함한다. 중복 원본/사본의 보호 정보는 모든 종류의 추천 통합에서 보존한다. Space Lens 용량은 읽기 가능한 로컬 일반 파일의 논리 크기; 링크·미다운로드 클라우드 제외, 하드 링크 중복 합산 방지, 중단과 부분 오류 표시.

유지보수는 고정 명령만 지원하고 임의 shell 입력은 받지 않는다. 권한이 필요한 작업은 앱에서 OS 관리자 인증으로 실행하며 취소·실패를 기록한다. 스냅샷 삭제는 복구할 수 없는 백업 제거임을 확인 창에 표시하고 단일 검증된 날짜 식별자만 전달한다. 개발 검증에서는 실제 개인 스냅샷·인덱스·DNS를 바꾸지 않는다.

타사 클라우드/메일 계정 연결, 범용 앱 업데이트 배포 엔진, 악성코드 엔진은 이 로컬 확장에 포함하지 않는다. 실제 구현 범위와 검증 결과를 비교 문서에 반영한다.
