# Permissions and full-scan flow

The first full scan opens a permissions checklist before expensive scanning. File access is probed with directory listings only; absent paths and non-permission failures are distinguished from access denial. The checklist covers Full Disk Access, Files and Folders, optional overload notifications and optional accessibility for paste. Administrator authentication remains tied to explicit maintenance/battery operations.

Users can finish all permission changes before one restart. Save a one-shot full-scan continuation before opening System Settings, because macOS can quit the app immediately. A new launch consumes the scope once, expires it after 24 hours and validates the folder with FileSafety. Cancelling setup removes the continuation. The restart button launches the same installed bundle after quitting. Permission changes themselves remain under macOS user control.

All terminology uses 검사. The sidebar has 전체 검사; completion opens 검사 결과 automatically. Recommended categories are expanded, direct-review categories are optional, and the primary action moves the selected recommendation plan to Trash after existing confirmation and revalidation. 한눈에 보기 provides a recent-result shortcut. Later scan errors remain visible in results instead of automatically interrupting with repeated permission modals.
