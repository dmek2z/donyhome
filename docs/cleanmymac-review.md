# CleanMyMac 대비 도니클린 기능 리뷰

2026-10-13 기준 MacPaw 공식 문서와 도니클린 실제 소스를 비교했습니다. CleanMyMac은 판매처와 Mac/OS에 따라 기능 범위가 다릅니다. 아래는 MacPaw Store판을 중심으로 비교하며, 동일 수준의 완전 대체라고 주장하지 않습니다.

## 핵심 사용 흐름

CleanMyMac의 Smart Care는 검사 → 추천 작업 자동 선택 → 상세 검토/제외 → Run 흐름입니다. 작업을 실행하기 전 결과를 보여주고 사용자가 실행합니다. 도니클린에도 **스마트 점검 → 추천 목록 → 추천 정리 실행**을 적용했습니다. [Smart Care 공식 설명](https://macpaw.com/support/cleanmymac/knowledgebase/smart-care)

| 기능 | 도니클린 상태 | 실제 동작과 남은 차이 |
|---|---|---|
| 통합 검사·자동 추천 | 구현 | 캐시·로그, 선택 폴더 큰 파일·중복, 설치 앱을 한 번의 작업으로 검사. 실시간 CPU·메모리도 함께 표시. 악성코드와 앱 업데이트는 이 검사에 포함하지 않음. |

| 추천 일괄 실행 | 구현 | 캐시·로그와 동일한 파일 사본을 자동 추림. 두 종류를 각각 제외할 수 있음. 확인 후 순차 휴지통 이동, 실행 직전 재검증과 항목별 성공/실패 기록. |
| 시스템 정리 | 미지원 | 시스템 캐시·로그, 언어 파일, 문서 버전, iOS 백업, Xcode 생성물·불완전 설정·삭제 사용자 흔적 등 전문 규칙 없음. |

| 타사 앱 일괄 업데이트 | 미지원 | App Store/Sparkle/업체별 업데이트 메타데이터와 설치 엔진 없음. |

| 악성코드·개인정보 보호 | 미지원 | 탐지 엔진·서명 DB, 실시간 보호, 브라우저 기록 정리·앱 권한 관리 없음. 보호 검사에 통과했다고 표시하지 않음. |
| Space Lens | 미지원 | 폴더별 용량 지도·버블 탐색 없음. 큰 파일 목록만 제공. |

| 도구함 추가 기능 | 미지원 | Gmail 정리·구독 취소, 화면 청소 모드 등 없음. |

CleanMyMac의 정리 범위와 선택 규칙은 [System Junk](https://cms-static.macpaw.com/support/cleanmymac/knowledgebase/system-junk), 나머지 모듈·판매처 차이는 [기능표](https://macpaw.com/support/cleanmymac/knowledgebase/missing-features), 추가 도구는 [My Tools](https://macpaw.com/support/cleanmymac/knowledgebase/my-tools)에서 확인했습니다. 도니클린의 상태는 `SmartScanner.swift`, `CleanupPolicy.swift`, `AppModel.swift`, 각 화면 구현에 근거합니다.

## 이 Mac의 메모리 관리

MacPaw 문서에서 **Free up RAM은 Intel Mac에서만 제공**한다고 명시합니다. 이 Mac은 Apple Silicon이므로 그 버튼을 그대로 흉내 내면 기능을 오해하기 쉽습니다. 도니클린은 높은 CPU/메모리 사용량을 추려서 일반 앱 종료를 요청하고 자원 변화량을 보여줍니다. 정렬만 하는 버튼은 “메모리순 보기”로 표시했습니다. [Maintenance Tasks](https://macpaw.com/support/cleanmymac/knowledgebase/maintenance-tasks)

## 추천 기준과 한계

- 캐시 앱: Chrome, Firefox, VS Code, Slack, Spotify, Figma, Edge, Brave의 정확한 bundle ID 캐시 폴더. 하위 파일·폴더 모두 14일 이상 변경 없어야 추천. 현재 실행 앱 ID 및 관련 ID가 있으면 제외.
- 로그: `.log`, `.log.gz`, `.log.숫자`. 모든 하위 항목이 30일 이상 변경 없어야 추천. 최근 변경·심볼릭 링크·읽기 실패·타입 불명·다른 파일 포함은 제외.
- 중복: SHA-256 후 실제 내용 비교. 하드 링크는 별도 복사본으로 세지 않음. 원본이 사라지거나 바뀌면 사본 정리 거부.
- 일반 사용자 파일은 오래됐거나 크다는 이유만으로 자동 삭제하지 않음. 앱 설정·컨테이너는 직접 검토.
- “자동”은 후보를 추리고 실행 버튼으로 일괄 처리하는 기능을 뜻함. 별도 스케줄러나 사용자 모르게 정리하는 백그라운드 작업은 아직 없음.
- 휴지통으로 이동한 크기는 즉시 확보 용량과 다름. 앱 종료 요청도 앱이 저장 창을 띄우거나 거부할 수 있어 실제 종료·확보 메모리를 보장하는 수치로 표시하지 않음.

## 우선순위

다음 확장 가치가 큰 기능은 프로젝트 생성물(Xcode DerivedData 등)별 규칙, 제거된 앱 잔여물 검토, 폴더 용량 지도입니다. 악성코드 검사·클라우드 삭제·범용 앱 업데이트는 별도 데이터와 검증이 필요합니다. 지금 버전에는 구현된 기능만 실행 가능합니다.
