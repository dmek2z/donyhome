# donyhome 2.2.0 검증

홈은 중앙 Mac 일러스트·전체 검사 행동과 한 장의 기기 상태 요약으로 구성했다. 개발은 프로젝트 목록과 실제 용량 분포/최근 활동/원격 확인 상세를 나란히 표시한다. macOS 실제 화면에서 처음 ViewThatFits가 긴 경로의 이상적인 폭 때문에 세로로만 표시되던 문제를 확인했고, 실제 콘텐츠 폭 640pt 기준 분기로 수정했다. 좁은 창에서는 같은 목록과 상세가 세로로 전환된다.

공통 폰트, 버튼, 메뉴, 64pt 목록 행을 사용한다. 알려지지 않은 용량은 미확인으로 표시한다. 그래프의 선택은 상세 조회이며 정리 체크박스와 분리한다. 단색과 컬러 캐릭터 설정을 홈 일러스트에도 적용한다.

154개 Core 테스트/29개 모음 통과. 검사 단계/중단, 공간 부족 지속 시간·쿨다운·회복, 최초 변경 직전 공간 측정, CLI 식별·현재 작업 폴더 보호·PID 재사용·부분 실패 복구·허용된 재개 등의 테스트를 포함한다. 앱 빌드 및 디자인 규칙 검사 통과.

저장 공간 추천 검사는 읽기 전용이고 기존 전체 검사 결과를 보존한다. 알림과 자동 검사는 독립적으로 켜고 끌 수 있다. 휴지통 이동한 바이트와 측정된 가용 공간 변화는 별도로 보고한다.

실제 사용자 파일 삭제·휴지통 비우기·실행 중인 CLI 신호 전송은 검증에서 수행하지 않았다. Cloud GPT 작업별 메모리 제어는 지원하지 않는다. 일시 정지는 RAM을 확보하는 기능이 아니며 UI에서 이를 안내한다.

실제 Mac에서 24개 연결 프로젝트를 읽기 전용으로 검사해 8.18GB의 확인된 용량 분포를 표시했다. 그래프 선택 시 해당 프로젝트 상세와 worktree 보호 사유가 바뀌는 것을 확인했다. 확인하지 못한 12개 결과는 숨기지 않고 일부 결과로 표시했다. 작업 탭의 보호된 호스트 제외 상태와 설정의 독립적인 공간 부족 옵션을 확인했다. 실제 전체 검사 시작 시 캐시·로그 → 개발 → 파일 단계가 바뀌는 것을 확인하고 중단을 요청했다. 시스템 파일 조회가 지연되어 중단 완료의 즉시성은 확인하지 못했다. 사용자 파일은 변경하지 않았다.
